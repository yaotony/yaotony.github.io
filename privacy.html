gog 隱私權政策

最後更新：2026 年 11 月 9 日

1. 用途

gog 是個人使用的影片上傳工具，唯一用途是將頻道擁有者本人的影片上傳到其本人的 YouTube 頻道。本工具不對外提供服務，也沒有其他使用者。

2. 存取的 Google 資料

gog 透過 Google OAuth 取得授權，僅使用 YouTube Data API 執行上傳影片及設定影片資訊（標題、說明、縮圖等）所需的權限。不讀取、不修改與上傳無關的資料。

3. 資料儲存

OAuth 授權憑證（存取權杖與更新權杖）只儲存在執行本工具的個人電腦上，不會上傳到任何伺服器或第三方。

4. 資料分享

gog 不收集、不出售、不分享任何個人資料給第三方。除頻道擁有者本人外，不處理任何其他人的資料。

5. Google API 服務使用者資料政策

gog 對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括其中的「有限使用」(Limited Use) 規範。

6. 撤銷授權

您可隨時前往 Google 帳戶權限設定 撤銷本工具的存取權，並刪除本機儲存的憑證檔案。

Privacy Policy (English)

Purpose. gog is a personal tool used solely to upload the channel owner's own videos to their own YouTube channel. It is not offered to anyone else.

Data accessed. gog uses Google OAuth and the YouTube Data API only for the permissions needed to upload videos and set their metadata.

Storage. OAuth tokens are stored only on the owner's local computer and are never sent to any server or third party.

Sharing. gog does not collect, sell, or share personal data with anyone. It processes no data belonging to anyone other than the owner.

Google API Services User Data Policy. gog's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at Google Account permissions.
